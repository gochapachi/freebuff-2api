## 5.5 测试基建建议（不引入重依赖）

- Mock 上游首选 `httpmock`（dev-dependency，轻量）；若新增 dev-dep 受限，用 `tokio::net::TcpListener` + 简单 HTTP 应答（当前 retry.rs 已有此模式，可复用）
- 所有测试**不写真实令牌、不打真实付费上游**（遵守付费 API 红线：Mock/录制验证）
- 新增测试文件进 `tests/`，保持 `#![cfg(test)]` 与 AAA 结构（Arrange-Act-Assert）
