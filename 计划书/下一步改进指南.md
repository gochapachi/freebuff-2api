# 下一步改进指南（Freebuff2API v0.7.3 → v0.8+）

> 本文件是**可执行改进清单**（核心交付物）。每项含：优先级、改动位置、行为差异、验收方式。
> 配套文档见 `计划书/` 目录：0 全景路线、2 架构加固、3 面板现代化、4 高可用安全、5 测试策略、6 功能扩展。

---

## 0. 总览

**结论**：项目质量高、架构清晰、验证充分（219 单测全绿 + 真实 E2E 矩阵），**无需重构**。改进集中在四件事：

1. **把"已宣称未落地"的能力补实**（双桶并发信号量——README 写了但代码没有）
2. **补齐 Claude 路径的能力差**（重试/记账/记忆——比 OpenAI 路径弱一截）
3. **面板体验现代化**（视觉品牌化 + 交互 + 可访问性 + 新增页）
4. **安全/高可用细节**（CSP、脱敏、端口冲突提示、桌面多开）

> 全部为"加法式"修改，不重构任何现有模块；默认配置与现行为完全一致，旧 config.json 免迁移。

## 1. 修复类（P0/P1 · 立即可做）

### 1.1 【P0】落地双桶并发信号量
- **位置**：新文件 `src/semaphore.rs`；接线 `api.rs`（chat / claude / web_bridge 三路径）；`config.rs` 加 4 个配置项
- **问题**：README/README_en 声称「免费 `{slot:1, multi:3}`、订阅 `{slot:3, multi:8}`」，但 `rg Semaphore` 零命中，转发路径无任何并发限制
- **改法**：tokio `Semaphore`（零新依赖），全局级，`TierGuard` RAII 自动归还；acquire 超时 2s 返回 429 语义
- **验收**：并发 N 请求同时通过数 ≤ 桶容量（Mock 上游测试）；单测覆盖两桶互不干扰/归还/超时
- **详见**：`计划书/2-架构加固方案.md §2.1` + `5-测试策略 §5.2A`

### 1.2 【P1】Claude 路径补齐重试 + 记账 + 记忆
- **位置**：`api.rs::handle_claude_messages`
- **问题**：`let _ = ensure_session(...)` 吞错；无换号重试；成功路径无 `usage_db.record_ex`/`telemetry.record`；无 `memory.observe`
- **改法**：把 OpenAI 路径的重试循环提取为公共 helper 复用；错误体转 Claude 形状（`openai_error_to_claude` 已有）；非流式成功补记账；记忆 observe 补调
- **验收**：Claude 排队返回 503+可读消息；5xx 自动换号（Mock 验证调用次数）；面板用量可见 Claude 请求；记忆开关开启时 observe 生效
- **详见**：`计划书/2 §2.2`

### 1.3 【P1】`handle_account_balance` Cookie 判定过宽
- **位置**：`api.rs` `looks_like_cookie` 闭包
- **问题**：`t.contains("%3A")` 会把任意 URL 编码串误判为 Cookie
- **改法**：收窄为 `session-token` / `.next-auth` / `callback-url`
- **验收**：单测补一条"非 Cookie 串不命中"断言

### 1.4 【P1】`web_threads` 绑定表无容量上限/TTL
- **位置**：`src/web_threads.rs`
- **问题**：绑定条目无限增长，`web_threads.json` 文件膨胀，长期运行内存累积
- **改法**：`MAX_BINDINGS`（默认 2000）+ 超 24h 条目清除；写文件时裁剪
- **验收**：单测注入 2001 条 → 最旧被裁剪；TTL 到期条目清除

### 1.5 【P2】`/v1/messages` 非流式成功路径无遥测/用量
- **位置**：`api.rs::handle_claude_messages` 非流式分支
- **改法**：`extract_usage` 解析 + `record_ex` + `telem.record`
- **验收**：Claude 非流式请求出现在面板用量/请求详情

### 1.6 【P2】桌面托盘「系统体检」跳转失效
- **位置**：`desktop/main.js`（`loadURL('#doctor')`）
- **问题**：非 hash 路由，`#doctor` 不触发前端 tab
- **改法**：改 `./ui#doctor` + 前端 `showTab` 读 `location.hash`
- **验收**：托盘点击体检 → 面板打开且停在「系统体检」tab

### 1.7 【P2】文档版本失真
- **位置**：`README.md` / `README_en.md`（`Setup 0.3.0` 等）
- **改法**：版本号统一为当前（0.8.0 语义），删除"信号量已实现"表述（落地后再写回）
- **验收**：全文搜索 0.3.0/0.2.0 无残留；与 CHANGELOG 对齐

## 2. 优化类（P1/P2 · 体验与健壮性）

### 2.1 面板视觉品牌化 + 组件规范
- **位置**：`src/web.rs`（内嵌 HTML/CSS/JS）
- **改法**：CSS 变量分层 token（色板/间距/圆角/阴影/动效）；统一按钮/卡片/表格/徽章/空态/骨架/抽屉/toast 组件 class；`prefers-reduced-motion` 尊重
- **验收**：320/768/1024/1440 断点无溢出；键盘 Tab 可达 + focus 可见；现有 E2E 面板断言保持通过
- **详见**：`计划书/3-面板现代化方案.md`

### 2.2 面板新增：对话测试台 + 设置页 + 关于页
- **位置**：`src/web.rs` 新增 tab
- **改法**：测试台调 `/v1/chat/completions` 流式渲染；设置页把现有 config 项（监听地址提示/记忆开关/token_saver/技能预算/代理/清理间隔）UI 化写回；关于页展示版本/上游/免责声明
- **验收**：每个控件点后有反馈；写回 config.json 生效（重启后仍在）
- **详见**：`计划书/3 §3.3`

### 2.3 大列表 windowed 渲染
- **位置**：`src/web.rs` 日志/记忆/请求列表
- **改法**：简单虚拟滚动（只渲染可视区 + 缓冲区），>500 条不卡
- **验收**：注入 2000 条日志滚动流畅；无内存暴涨

### 2.4 响应安全头 + CSP
- **位置**：`api.rs` / `web.rs` 响应构造
- **改法**：`/ui`、`/healthz`、`/v1/*` 加 `X-Content-Type-Options: nosniff`、`Referrer-Policy: strict-origin-when-cross-origin`；面板页加 CSP `default-src 'self'`
- **验收**：curl -I 可见头部；面板功能不受影响（无外部资源）

### 2.5 日志/遥测脱敏开关
- **位置**：`api.rs` 遥测记录处
- **改法**：`redact_logs` 配置项（默认开）：记录前把 `session-token=...`、`Bearer xxx`、`authorization` 值替换为 `***`
- **验收**：导入含 Cookie 的错误体写入遥测时无明文 token

### 2.6 桌面多开保护
- **位置**：`desktop/main.js`
- **改法**：`app.requestSingleInstanceLock()`；二次启动 `show()` 已有窗口
- **验收**：连开两次安装版 → 只弹一个窗口、一个网关进程

### 2.7 端口绑定失败中文错误
- **位置**：`src/main.rs` 启动 bind
- **改法**：`bind` 失败捕获 → 输出"端口 X 被占用，请修改 config.json 的 listen_addr"（含进程提示可选）
- **验收**：占用 47821 再启动 → 明确中文报错而非裸 anyhow

## 6. 风险与依赖

- 信号量接入点位于核心转发路径（首字节前 acquire）——**必须**先在 Mock 上游测试验证，再改线上行为；默认值按 1/3/3/8 开启可能让"单账号免费层"请求并发变低——**默认给 1/3/3/8 即可**（单账号本来也只有 1 个会话），多账号才吃桶。
- Router 级测试需要 `AppState` 可注入：`UpstreamClient` 指向 Mock 地址即可（`base_url` 可配），无需改动结构。
- 面板 88KB 内嵌字符串拆分（`web_assets/`）是**纯文件组织**，不引入构建系统；若担心 diff 噪音，可暂缓拆分只做 CSS 变量层。
- 遥测脱敏默认开会影响 `error_excerpt` 可读性（Cookie 段被掩码）——权衡后默认开（安全优先），面板展示时已非敏感。
