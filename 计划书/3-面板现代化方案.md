# 3. 面板现代化方案（v0.8 UI/UX）

> 当前面板：单 HTML + 原生 JS（src/web.rs 内嵌 88.7KB，GitHub Dark 风格），无构建。**本文只给设计指南与落地点，不改代码。**

---

## 3.1 现状评估（证据）

- 视觉：GitHub 深色（`--bg:#0d1117`），可读性好但**通用、无品牌**；卡片/表格/徽章是唯一组件语言
- 交互：Tab 内切换、抽屉详情、SSE 实时日志、toast、一键复制——**该有的都有**
- 短板：
  1. 无响应式精细断点（920px 单栏，手机/窄窗体验一般）
  2. 无键盘可达性标注（焦点可见性、ARIA 角色、`tabindex` 遍历）
  3. 无 loading/骨架态（数据请求时卡片空闪）
  4. 无深色/浅色主题切换（`prefers-color-scheme` 未用）
  5. 无「刷新时机」反馈：SSE 重连、请求超时、凭证过期只在日志里，无全局状态条
  6. 新增数据（记忆、技能、账号）用 `innerHTML` 重建——无虚拟滚动，条目多了卡顿（记忆/日志量大时）

## 3.2 设计方向（推荐：暗色仪表盘 + 品牌化）

| 维度 | 现状 | 目标 |
|------|------|------|
| 配色 | GitHub Dark 默认 | 品牌化暗色：主色 `#4f8cff` 系 + 状态色（ok/warn/err）+ 语义化 token 化（CSS 变量已具备，扩充分层 token） |
| 字体 | 系统栈 | 引入更现代的等宽/中文栈（可选：局部字体子集，不引入外部字体库） |
| 布局 | max-width 1240 单流 | 保持单流但加 sticky 摘要条（uptime/账号数/今日用量实时更新）；窄屏折叠导航为横向滚动 |
| 组件 | 卡片/表格 | 统一组件规范：卡片、表格、徽章、按钮、输入、空态、骨架、toast、抽屉、开关、标签页——**形成面板组件库**（CSS class 约定） |
| 动效 | 无 | 轻量微交互：hover 提亮已有，加 focus-visible 焦点环、抽屉滑入、toast 滑入、数字滚动（可选） |
| 可访问性 | 弱 | `aria-label` / `role="tablist"` / 键盘可达 / `:focus-visible` 焦点环 / 对比度 ≥ 4.5:1（badge 已达标） |
| 数据展示 | innerHTML 全量重建 | 大列表（日志/记忆/请求）分页或虚拟滚动；新增空态引导插画（emoji + 文案 + 下一步按钮） |

## 3.3 新增/增强页（与后端 API 对齐，全部用现有接口）

| 页面 | 数据源 | 内容 |
|------|--------|------|
| **总览增强** | `/api/usage/totals` + `/api/guide` + `/healthz` | 顶部摘要条（uptime/账号/模型/今日用量）+ 趋势 Sparkline（用 `/api/usage/daily` 画 7 天迷你条，纯 CSS/SVG，零依赖） |
| **账号增强** | `/api/tokens` + `/api/account/overview` + `/api/account/history` | 账号卡片化：头像/昵称/邮箱/套餐徽章/今日剩余/健康点；批量刷新按钮（Promise.all 并发检查） |
| **实时日志增强** | `/api/logs/stream` | 自动滚动开关、错误过滤持久化（localStorage）、搜索高亮、断线重连状态条 |
| **体检增强** | `/api/doctor` | 一键重跑 + 逐项展开修复建议 + 复制诊断报告（复制成 Markdown） |
| **接入指南增强** | `/api/guide` | 每段配置加「复制」按钮（已有）；新增 C#/Go SDK 示例；模型列表选择器（从 /v1/models 拉取下拉） |
| **新增：设置页** | 现有配置 API | 监听地址/端口（提示改后重启）、记忆开关（已有）、token_saver 开关、技能注入模式/预算、代理、会话清理间隔——统一 UI 化，写回 config.json |
| **新增：关于页** | `env!("CARGO_PKG_VERSION")` + `/healthz` | 版本、构建信息、上游地址、免责声明、检查更新（桌面版桥接） |

## 3.4 前端工程化建议（不加构建系统）

- 保持「无构建」：CSS 变量 + 原生 JS，遵守现有风格
- **抽取小工具集**：`esc/badge/fmtTime/api/toast` 已是函数——新增 `debounce/throttle`、`virtual-list`（简单 windowing）、`sparkline`（纯 SVG）
- **代码组织**：web.rs 内嵌字符串已 88KB，建议拆 `src/web_assets/{index.html,app.js,app.css}` 三块，Rust 侧 `include_str!` 拼装（**保持无构建**，只是文件分离，便于编辑与 diff）
- **兼容**：所有改动向后兼容现有 fetch/SSE 接口；不引入 fetch/依赖

## 3.5 验收清单（前端）

- [ ] 320 / 768 / 1024 / 1440 断点无溢出、无截断
- [ ] 键盘 Tab 遍历可达所有按钮/输入/开关，focus 可见
- [ ] 深色/浅色（可选）或至少 `prefers-reduced-motion` 尊重
- [ ] 大日志（>1000 条）滚动流畅（windowed render）
- [ ] 请求失败有明确 toast + 状态条（不静默）
- [ ] 空态有引导（去添加账号 / 去导入 / 去启用技能）
- [ ] 现有 E2E 断言（phase_g / phase_i 面板相关）全部保持通过
