# Freebuff2API 项目全景与版本路线图（刷新至 v0.10.0）

> 「计划书」入口索引。阅读顺序：0 → 2/3/4 → 5 → 6 → 下一步改进指南。每版本发布后本文件必须刷新（防漂移）。

## 一、项目一句话
把 Freebuff（codebuff.com）免费层模型能力逆向封装为本机 **OpenAI 兼容 + Anthropic 兼容** 网关：Rust(axum) 单二进制 + 内嵌单页面板 + Electron 桌面壳 + 浏览器扩展登录。

## 三、能力地图（v0.10 已实现）
- 双协议出口（OpenAI/Anthropic，流式+非流式+协议互转）
- 多账号智能轮询：Bearer 池（健康分+熔断三态+指数冷却）+ web Cookie 池（v0.9，401 冷却/轮询/健康看板）
- **上游模型策略合同实时化（v0.10）**：availability（always/deployment_hours/off_peak_only 时间窗）+ availableAt + available_at 透出 + 快照同步（refresh_strategy_from_snapshot）+ 表外模型"未经策略验证"标注 + mimo/mimo-v2.5 收录
- 双桶并发信号量（槽/并发，免费 1+3 / 订阅 3+8）
- 会话保活 + 广告换额度；记忆层（默认关，可热切换）
- 技能系统（文件真相源 + roster 注入 + 质量门）
- 面板（v0.10 可访问性：ARIA tabs/键盘/44px/aria-live；日志筛选/暂停/导出/错误徽标；推荐卡可用性列；凭证冷却提醒；上传校验）
- 可观测：遥测 SQLite + "三最"聚合（/api/usage/insights）+ 实时日志 SSE + 系统体检 + 用量
- 登录：WebView2 内嵌 / 浏览器扩展 / 剪贴板 / 手动导入；全配置导出/导入
